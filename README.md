# The E-MTB Evolution

Five riding seasons (2022–2026) compared: what changed when David's acoustic mountain bike was stolen and he moved to e-MTBs. Interactive charts let you switch between measures, compare 2026 with different baselines, count each season's climbing in Everests, and estimate climbing for a ride of a given length.

**View the page: https://deuber.github.io/e-mtb-evolution/**

Data: season totals from Strava. 2026 is counted through early November.
